- **Возможности**: регистрация, два сообщения, YAML, статистика, доступ администратора.
- **Установка**: Python 3.14, виртуальное окружение, зависимости, .env, папка data.
- **Запуск**: отдельные команды бота, веб-сервера и туннеля; настройка /setmenubutton.
- **Архитектура**: обработчики → сервисы → репозитории → SQLite; отдельный фоновый исполнитель.
- **Ограничения**: один исполнитель, отсутствие автоматических повторов для FAILED, возможный дубль при сбое между отправкой Telegram и записью SENT.

# Запуск

1. Создайте и активируйте виртуальное окружение
```bash
python3 -m venv .venv
source .venv/bin/activate
```

2. Установите зависимости
```bash
pip install -r requiremenets.txt
```

3. Скопируйте окружение переменных и заполните его актуальными данными
```bash
cp .env.example .env
```

4. Запустите приложения в отедльных терминалах
```bash
# Запуск Telegram Бота
python3 main.py

# Запуск бэкенд сервиса статистики
uvicorn app.web:app --reload

# ОПЦИОНАЛЬНО: запуск через ngrok для HTTPS подключения
ngrok http 8000
```
